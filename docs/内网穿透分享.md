# 内网穿透分享（把本机站点临时开放给他人）

不用买服务器、不用信用卡、不用注册任何云平台——用 Cloudflare 的免费隧道，把本机的 3000 端口映射成一个公网 HTTPS 地址，发给朋友即可访问。

**适合**：想马上让别人体验、模型接口在内网（云端访问不到）、只是临时分享。
**不适合**：要长期在线、要固定不变的网址——那得上服务器或托管平台，见 [部署到 Render](./部署到Render.md)。

代价只有一条：**你的电脑必须开着**，关掉进程或休眠，外网就断。

---

## 一、装一次 Cloudflare Tunnel

Windows 用 winget（一次即可，之后不用再装）：

```powershell
winget install --id Cloudflare.cloudflared -e --accept-source-agreements --accept-package-agreements
```

装完的可执行文件在：

```
C:\Program Files (x86)\cloudflared\cloudflared.exe
```

（若你的机器装到了别处，用 `Get-ChildItem "C:\Program Files*","$env:LOCALAPPDATA" -Filter cloudflared.exe -Recurse -Depth 4` 找一下。）

---

## 二、配好环境变量（`.env`）

分享前建议至少设这几项，改完**重启网站**才生效：

| 变量 | 建议值 | 作用 |
| --- | --- | --- |
| `APP_SECRET` | 一长串随机字符 | 登录会话 cookie 的签名密钥，不设就用代码里的默认值，公开环境下等于没锁 |
| `ADMIN_PASSWORD` | 你自己记住的口令 | 设了之后 `/admin` 须先输口令，访客改不了模型密钥与人物启停 |
| `HIDE_ACCOUNT_LIST` | `true` | 登录页不罗列已有账号名，防止陌生人拿账号名试口令 |
| `ALLOW_SIGNUP` | `false` | 关闭注册，账号由你手工分发；**库里一个账号都没有时会自动放行** |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | 你现在用的那套 | 访客不用自己配密钥，注册即可直接开辩；token 走你的额度 |

样例见 `.env.example`。

## 三、启动

### 方式 A：开两个终端（看得见日志，推荐第一次用）

终端 1 —— 起网站（生产模式，比 `dev` 快得多）：

```bash
cd d:/tmp/head-metting
npm run build   # 改过代码就要重新构建
npm start       # 监听 http://localhost:3000
```

终端 2 —— 打通隧道：

```powershell
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:3000
```

屏幕上出现这一行就说明通了：

```
|  https://xxxx-xxxx-xxxx.trycloudflare.com  |
```

### 方式 B：后台静默启动（关掉窗口也还在跑）

```powershell
cd d:/tmp/head-metting

# 网站
Start-Process -FilePath "cmd.exe" -ArgumentList "/c npm start > d:\tmp\head-metting\.share-next.log 2>&1" -WorkingDirectory "d:\tmp\head-metting" -WindowStyle Hidden

# 隧道
Start-Process -FilePath "C:\Program Files (x86)\cloudflared\cloudflared.exe" -ArgumentList "tunnel --url http://localhost:3000" -RedirectStandardOutput "d:\tmp\head-metting\.share-tunnel.log" -RedirectStandardError "d:\tmp\head-metting\.share-tunnel.err.log" -WindowStyle Hidden
```

拿地址：

```powershell
Get-Content .share-tunnel.log | Select-String "trycloudflare.com"
```

`.share-*.log` 是临时日志，删掉无妨。

## 四、关闭

```powershell
# 1) 停隧道（外网立刻不可达）
Stop-Process -Name cloudflared -ErrorAction SilentlyContinue

# 2) 停网站（结束占用 3000 端口的进程）
$p = (Get-NetTCPConnection -LocalPort 3000 -State Listen -ErrorAction SilentlyContinue).OwningProcess
if ($p) { Stop-Process -Id $p -Force }
```

只停隧道、不停网站，本机 `http://localhost:3000` 还能照常用。

---

## 五、重启与地址变化

- **地址每次启动都会变**（`xxxx.trycloudflare.com` 是随机的）。重启后要重新发地址给朋友。
- 想拿到固定地址，需要注册一个 Cloudflare 账号（免费、免信用卡）+ 一个域名，改用常驻 named tunnel。
- 电脑**别休眠**：合盖或睡眠后隧道会断。电源设置里把睡眠关掉。
- 免费隧道没有可用性承诺，Cloudflare 可能限速或回收，长时间挂着建议还是上托管平台。

## 六、常见问题

**朋友说打不开**
先自己用手机流量试。若大面积打不开，多半是 Cloudflare 域名在本地网络被干扰，换一条线路试试：

```bash
npx localtunnel --port 3000
```

同样免注册免卡，会给出另一个 `*.loca.lt` 地址。

**页面能开但一开辩就报错**
多半是模型接口调不通。本机访问得到不等于外网访问得到——若 `LLM_BASE_URL` 是内网地址（如 `*.ruijie.com.cn`），只有本机发起的请求才通，这恰恰是内网穿透方案的优势。

**访客太多，token 烧得快**
设 `ALLOW_SIGNUP=false` 关闭注册，账号由你手工发；已有账号可直接在数据库里删除。

**想看看谁在用**
账号与辩录都在 `prisma/dev.db`，用任何 SQLite 工具打开即可查看；删号前记得先备份这个文件。

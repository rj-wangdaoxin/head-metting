# 交互与界面说明（UE / UI）

整体风格：**中式古典水墨**。宣纸米色底（`#F6F1E7`）、墨黑主体（`#2B2B28`）、朱砂（`#9E3B2E`）与靛青（`#35566B`）点缀；方形印章式头像、云纹分隔（`CloudDivider`）、竖排标题（`VerticalTitle`）、卷轴卡片（`ScrollCard`）；标题与人名落款走宋体栈，正文走思源黑体栈。微动效克制：卡片悬停浮起、印章淡入、流式文字光标闪烁、轮次分隔线随推进展开。

## 一、全局导航

固定顶栏（高 64px）：「史」字印章 + 品牌名「青史群贤」+ 五个入口：人物库 / 分身 / 论辩 / 辩录 / 后台。当前项以朱砂下划线（`line-grow` 动画）标示。主内容区统一 `pt-16` 避免遮挡。

## 二、页面与流程

### 1. 人物库 `/figures`

- **筛选区**（`FilterBar`，状态同步到 URL：`?dynasty=&category=&q=`）：朝代 chips（不限 + 8 朝）、类型 chips（不限 + 10 类）、检索框（320ms 防抖后写入 URL）。
- **卡片网格**（`FigureCard`）：1–4 列响应式。含印章/画像头像、姓名、字号、`朝代·类型·生卒` 徽标、一段核心思想（两行截断）、前三个性格标签。
- 空结果给出「此筛选之下，未见其人」并提示放宽条件。
- 点击卡片 → **人物档案** `/figures/[slug]`：左列头像与大印章，右列姓名、字号、`官方本体 · 不可修改` 徽标、朝代/类型/生卒/籍贯/身份/性格标签；下方依次为 生平 / 核心思想 / 语言风格（自称 + 习惯用语）/ 代表言论（朱砂引线 + 出处）/ 典故轶事 / 所长 / 立言之禁 / 史料来源 + 头像来源。底部两个动作：**据本体创建分身**、**邀其入论辩**。

### 2. 分身 `/personas`、`/personas/new`、`/personas/[id]/edit`

- **列表**（`PersonaCard`）：本体头像 + 分身名 + 「本体：某人 · 朝代 · 类型」+ 语气/约束/知识侧重标签 + 差异摘要；操作为 调整 / 复制 / 删除（两步确认）。
- **表单**（`PersonaForm`）：本体下拉（按朝代分组，编辑时锁定）→ 分身名 → 性格倾向 → 语气风格（承本体 / 文言 / 半文半白 / 激昂 / 冷峻 / 诙谐 / 平实）→ 知识侧重（十项多选 chips）→ 立场偏移 → 额外设定 → 人设约束强度滑条（1–5，附释义）。
- 从档案页进入时自动预选本体，并将本体「所长」前三项预置为知识侧重，分身名默认「某·分身」。

### 3. 论辩 `/debate`（设席）

1. 输入话题（附 5 条示例话题可一键填入，限 120 字）与背景（可不填）。
2. **选角**（`CastPicker`）：Tab 切换「官方本体 / 我的分身」，卡片式多选，达上限后其余置灰；已选角色以印章条展示，可逐个移出。
3. 轮数滑条（受后台下限/上限约束）、**言谈语体**（随人物 / 文言 / 半文半白 / 白话，默认取后台设置）与「判官评点」开关。
4. 「设席开辩」→ 创建会话并跳转舞台。

### 4. 论辩 `/debate/[id]`（舞台）

三栏布局（窄屏收为单栏）：

- **左栏·同席**：每位参与者印章 + 姓名 + 朝代，右侧「@」按钮可点名其立即发言（生成中或已结束时禁用）。
- **中栏·对话流**：开场卡（话题 + 背景）→ 按轮次与阶段分隔（「第 N 轮」「结辩」）→ 角色气泡（印章 + 姓名 + 朝代，气泡左侧描边取该角色墨色，结辩发言带金色「结辩」标，被中断的发言标「（中断）」）；用户/主持消息右对齐显示。流式生成时显示「（凝神构思……）」并逐字推进，光标闪烁。结束后追加**辩要**（鎏金描边）与**判官评点**（靛青描边）卡片。
- **底部控制栏**：
  - `推进本轮（余 n 人）`：**一轮 = 同席按座次各发言一次**，一次点击即串行走完本轮；若本轮已毕则显示 `推进下一轮`；结辩阶段显示 `完成结辩（余 n 人）`。生成中按钮变为 `发言中……` 并出现 `中断`（保留已生成片段）。
  - 可输入插话，回车发送；`手/法槌` 图标切换「提问者 / 主持」身份，主持指令以不同标签呈现。
  - `收束成辩要`：随时提前结束并产出辩要。
  - 结束后：`导出辩录`（Markdown 下载）、`续一场（余 N 次）`、`另立话题`。
- **右栏·本场**：阶段徽标（论辩 / 结辩 / 已毕）、`第 n / N 轮`、`本轮 x / N 人已发言`、`待发言：某某、某某`、本场语体、发言条数与上限、判官开关状态、进度条；下方「用法」提示卡。

### 5. 辩录 `/debate/history`

按更新时间倒序列出会话：话题（可点入回看）、阶段徽标、`人数 · 条数 · 轮数`、续场次数、时间、参与者印章；行内操作：回看 / 导出 / 续一场（未达上限时）/ 删除（两步确认）。

### 6. 后台 `/admin`

分区卡片：
1. **模型接口**：base_url、api_key（密码框）、model、temperature、max_tokens、超时；`保存配置` 与 `连接测试`（测试使用当前表单值，不落库）。
2. **论辩规则**：九项数值配置 + 新建辩论的默认语体 + 判官评点默认开关。
3. **内置人物**：可检索列表，逐行显示头像、朝代/类型/头像来源、启用开关；展开「头像」可粘贴地址抓取、上传本地图片、还原为默认头像。
4. **角色立言通则**：只读展示 Prompt 规则模板及其组合说明。

## 三、状态与反馈约定

- 所有破坏性操作（删除分身、删除辩录）均需二次确认。
- 生成失败/未配置模型时，控制栏上方出现朱砂提示条，给出具体原因（如「尚未配置模型密钥」）。
- 禁用态统一 `disabled:opacity-40` + `cursor-not-allowed`，不隐藏按钮以免布局跳动。
- 长列表滚动区域统一细滚动条（`thin-scrollbar`），避免视觉噪音。

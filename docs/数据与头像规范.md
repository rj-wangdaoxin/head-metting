# 数据与头像规范

## 一、人物种子数据

数据位于 `seed/figures/*.json`，按朝代分文件（`pre-qin`、`qin-han`、`three-kingdoms`、`sui-tang`、`song`、`yuan`、`ming`、`qing`），每文件为一个数组。当前收录 **40 人 / 8 朝代**：

| 朝代 | 人数 | 代表 |
| --- | --- | --- |
| 先秦 | 5 | 孔子、老子、孙武、韩非、屈原 |
| 秦汉 | 5 | 秦始皇、刘邦、项羽、韩信、司马迁 |
| 三国两晋南北朝 | 6 | 曹操、诸葛亮、司马懿、周瑜、关羽、陶渊明 |
| 隋唐 | 5 | 李世民、魏征、李白、杜甫、玄奘 |
| 宋 | 6 | 苏轼、辛弃疾、岳飞、王安石、朱熹、李清照 |
| 元 | 2 | 成吉思汗、关汉卿 |
| 明 | 6 | 王守仁、朱元璋、张居正、戚继光、唐寅、郑和 |
| 清 | 5 | 康熙、纪昀、曹雪芹、曾国藩、林则徐 |

### 字段规范

| 字段 | 类型 | 约束（校验脚本强制） |
| --- | --- | --- |
| `slug` | string | 小写字母/数字/连字符，全局唯一 |
| `name` / `courtesy` | string | 姓名必填；字号可为空（后世称号加括号注明，如「（唐太宗）」） |
| `dynasty` | enum | 先秦 / 秦汉 / 三国两晋南北朝 / 隋唐 / 宋 / 元 / 明 / 清 |
| `category` | enum | 文官 / 武将 / 谋士 / 诗人 / 作家 / 思想家 / 帝王 / 其他 |
| `birthYear` / `deathYear` | int \| null | **公元前用负数**（如孔子 `-551`）；不确定填 `null` 并在 `biography` 中说明 |
| `birthplace` | string \| null | 古地名 + 今地名括注 |
| `roles` | string[] | ≥1，身份官职 |
| `biography` | string | ≥60 字，履历脉络 |
| `personalityTraits` | string[] | ≥3，四个字内为宜 |
| `speakingStyle` | object | `selfAddress`（自称）、`tone`（≥10 字）、`catchphrases`（≥2） |
| `thoughts` | string | ≥20 字，核心思想，用于卡片摘要 |
| `quotes` | `{text, source}[]` | ≥2，**必须附出处** |
| `anecdotes` | string[] | ≥1 |
| `expertise` | string[] | ≥3，兼作分身「知识侧重」预设 |
| `taboos` | string[] | ≥3，须明确「不谈/不涉」后世内容 |
| `sources` | string[] | ≥2，史料来源 |

校验：

```bash
npm run validate:figures
# 共校验 104 位人物，失败 0 项，覆盖 8 个朝代文件。
```

校验项包括：字段完整性与长度、枚举合法性、`slug` 唯一性、生卒年不颠倒、禁忌条目是否含后世限定。失败会逐条输出路径与原因并以非零码退出。

### 导入与不可变性

`prisma/seed.ts` 按 `slug` upsert：

- **历史字段**每次以 JSON 为准覆盖（确保种子是唯一事实来源）；
- **`enabled` 不被覆盖**，保留后台的启停状态；
- 头像字段依据 `seed/avatars.result.json` 写入。

应用层只有两处可以写 Figure：`toggleFigure`（仅 `enabled`）与头像三个动作（仅 `avatarUrl/avatarKind/avatarSource`）。UI 不提供任何档案编辑入口。

## 二、头像策略


优先级：**平台原创 Q 版绘制头像 > 程序化水墨默认头像**。头像是矢量绘制的 Q 版形象，不采用任何第三方图片，因此无版权风险；也绝不采用游戏立绘、现代商业插画等受版权保护的素材。

### 1. Q 版绘制头像（默认全部人物都有）

由 `scripts/generate-avatars.mjs` 按人物特征程序化生成 200×200 SVG → `public/avatars/{slug}.svg`：

- **构图**：大头身比（头约占画面一半）、圆脸大眼带高光、腮红、小身体 + 交领袍 + 腰带、左下朱砂起首章（姓氏）、朝代色背景晕染与外圈双线。
- **人物特征**由 `seed/q-looks.json` 逐人配置：冠帽（冕旒/幞头/长翅乌纱/纶巾/东坡巾/方巾/兜鍪/先秦冠/束发/女髻/道冠/斗笠/清冠）、道具（羽扇、书卷、竹简、剑、枪矛、弓、毛笔、酒壶、笏板、印玺、葫芦、笛箫、琴、画卷、节杖、帅旗、玉璧、浑天仪、烟袋、图卷、兰草、蝶、规矩等）、须眉（长髯/络腮/短须/八字/山羊胡）、表情（眉/眼/嘴）、服色与镶色、瞳色（孙权碧眼）、面肤（包拯黑面）、眼镜（曾国藩、李鸿章）。
- 未配置的人物按类别套默认造型（帝王冕旒持玺、武将兜鍪佩剑、谋士纶巾羽扇、文官乌纱持笏、诗人束发持卷、词人持画卷、思想家持竹简、史家持简册、其他持书），服色与朝代色相配。

```bash
npm run avatars          # 生成缺失的头像
npm run avatars:force    # 全部重新生成（改完 q-looks.json 后执行）
```

结果写入 `seed/avatars.result.json`（含 `ok/url/source`），`prisma/seed.ts` 据此写入 `avatarUrl`、并把 `avatarKind` 置为 `QVER`。

### 2. 默认头像（兜底）

`FigureAvatar` 以 SVG 程序化生成：朝代色双线印章框 + 中心大字（取姓名末段首字，如「爱新觉罗·玄烨」取「玄」）+ 右上圆形类型符号（玺/笏/戈/筹/诗/词/文/道/史/墨）+ 底部朝代小字。页面加载 `<img>` 失败（`onError`）时会降级到该 SVG，保证永不出现破图。

### 3. 后台手动绑定

`/admin → 内置人物 → 头像`：粘贴图片地址由服务端下载压缩，或直接上传本地图片；亦可「还原」为默认头像。来源信息会记录在档案页底部。

## 三、分辨率与体积

- Q 版头像为矢量 SVG，单枚约 3–5KB，100 枚合计 < 500KB，任意尺寸清晰。
- `public/avatars/` 中生成的图片已在 `.gitignore` 中忽略，可通过脚本重新生成。
